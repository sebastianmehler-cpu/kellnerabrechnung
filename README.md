# Funktionen

## Dashboard

Anzeige von:

- 💰 Umsatz
- 🎫 Provision
- ➖ Abzüge
- 💵 Auszahlung

---

## Getränke

Für jedes Getränk:

- Name
- Anzahl
- Preis
- Summe

Funktionen:

- Getränk hinzufügen
- Getränk löschen
- Preis ändern
- Name ändern

---

## Abzüge

Für jeden Abzug:

- Name
- Anzahl
- Wert
- Summe

Funktionen:

- Abzug hinzufügen
- Abzug löschen
- Wert ändern
- Name ändern

---

## Provision

Berechnung:

```text
Provision = Umsatz × Prozent
```

Auszahlung:

```text
Auszahlung =
Umsatz
- Provision
- Abzüge
```

---

## Speicherung

### ⚙️ Konfiguration speichern

Speichert dauerhaft:

- Getränke
- Getränkepreise
- Abzugsarten
- Abzugswerte

### 💾 Abrechnung speichern

Reserviert für zukünftige Tagesabschlüsse.

---

## 🆕 Neue Abrechnung

Setzt zurück:

- Mengen Getränke
- Mengen Abzüge

Bleibt erhalten:

- Getränkenamen
- Getränkepreise
- Abzugsarten
- Abzugswerte

---

## 📄 PDF

Druckansicht über Browser.

Geeignet für:

- Tagesabschluss
- Vereinsablage
- Veranstaltungsnachweis
